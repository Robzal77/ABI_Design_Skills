# abi-newsletter

## When to use
Generate email newsletters.

## Method
Use npm run newsletter -- --brief examples/brief.json --out output/newsletter.html. Avoid invented announcements and use approved distribution lists.

## Validation and handoff
Preview in target clients, especially Outlook.

## Governance
Follow AGENTS.md and brand/PROVENANCE.md. Do not invent claims, assets, approvals or functionality. Save editable source and identify remaining manual checks.
