# abi-powerbi

## When to use
Design Power BI report themes.

## Method
Use python avi.py --format powerbi --brief examples/brief.json --out output/theme.json. Creates THEME JSON only, not PBIR/PBIP or report pages.

## Validation and handoff
Validate in Power BI Desktop; preserve semantic logic.

## Governance
Follow AGENTS.md and brand/PROVENANCE.md. Do not invent claims, assets, approvals or functionality. Save editable source and identify remaining manual checks.
