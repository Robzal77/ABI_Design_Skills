# abi-web

## When to use
Generate basic web visual previews.

## Method
Use python avi.py --format web --brief examples/brief.json --out output/landing.html. This is static HTML and does not alter a production app.

## Validation and handoff
Test responsive layout, keyboard behavior and browser rendering.

## Governance
Follow AGENTS.md and brand/PROVENANCE.md. Do not invent claims, assets, approvals or functionality. Save editable source and identify remaining manual checks.
