# abi-graphics

## When to use
Create scalable posters and infographic foundations.

## Method
Use python avi.py --format graphics --brief examples/brief.json --out output/graphic.svg. Editable SVG, without embedded proprietary logo.

## Validation and handoff
Open in browser and review wrapping, crop, legibility.

## Governance
Follow AGENTS.md and brand/PROVENANCE.md. Do not invent claims, assets, approvals or functionality. Save editable source and identify remaining manual checks.
